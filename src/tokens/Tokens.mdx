# Design tokens

Tokens are written once in `src/tokens/tokens.ts`. `npm run tokens` turns them into CSS custom properties
in `src/styles/tokens.css`, all prefixed `--gds-`.

| Tier | Example | Who uses it |
| --- | --- | --- |
| Primitive | `--gds-color-indigo-600`, `--gds-blur-md` | Only semantic tokens |
| Semantic | `--gds-surface-glass`, `--gds-text-primary` | Components and consumers |
| Component | `--_fill`, `--_height` (private, inside a CSS Module) | That one component |

## Theming

- Light is the default. Dark follows `prefers-color-scheme` automatically.
- `data-theme="light"` or `data-theme="dark"` on `<html>` (or any subtree) forces a theme.

## Glass accessibility

Every glass surface falls back to an opaque `--gds-surface-solid*` when:

- the browser does not support `backdrop-filter`
- the user prefers reduced transparency
- the user prefers more contrast
- forced-colors (Windows High Contrast) mode is on
